# Contributing

Useful contributions include improving beginner-friendly explanations, fixing setup problems, adding architecture diagrams, improving cleanup, adding safe practice exercises, improving documentation, or adding a genuinely different AI architecture.

A new lab should document:

1. Technology stack
2. Architecture
3. Data flow
4. Trust boundaries
5. Storage needs
6. Dependencies
7. Safe practice scope
8. Cleanup procedure

Avoid adding many copies of the same vulnerable chatbot. The goal is architectural diversity.

Do not submit real credentials, tokens, private data, or instructions intended for unauthorized access.
